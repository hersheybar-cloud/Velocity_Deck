# Velocity_Deck
What: General Description: A small keyboard addition to the Macbook pro to do Onshape quickly and learn PCB design. 
     - able to do 2 types of modes 
         - one specifically for Onshape 
         - one for KiCad 
     - an in between button to switch the two. <br>
     
    Total: 12 Cherry MX key switches + 2 rotary encoders. 
    
Why: a Macropad with optimal traces + code to make it as a fast as possible at taking inputs
